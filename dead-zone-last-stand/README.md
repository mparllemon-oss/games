# Dead Zone: Last Stand

A dependency-free, browser-based top-down zombie survival game built with JavaScript ES modules, Canvas, and CSS. All game art is drawn locally; sound effects and the ambient drone are generated by Web Audio. Progress and settings are saved in the browser's LocalStorage.

## Run locally

Requires Node.js 18 or newer. No external dependencies are required.

```bash
npm install
npm run dev
```

Open the printed URL (normally `http://localhost:4173`). To serve the production build, run `npm run build` followed by `npm run preview`.

## Controls

- WASD / arrow keys: move
- Mouse: aim; hold left click to fire
- R: reload; 1–5: select an owned weapon
- Escape: pause; F: fullscreen
- Touch: left stick moves; right stick aims and fires; use the reload and switch buttons

## Project layout

- `index.html`: game shell and interface regions
- `src/game.js`: canvas renderer, player, combat, enemy AI, waves, loot, and upgrades
- `src/ui.js`: menus, HUD, shop, settings, and overlays
- `src/data.js`: weapon, enemy, and upgrade balancing data
- `src/save.js`: safe LocalStorage persistence
- `scripts/build.mjs`: static production build into `dist/`
- `scripts/smoke-test.mjs`: gameplay and persistence smoke tests

The Continue Run checkpoint is saved between cleared waves. It resumes at the next wave with the saved survivor, weapons, ammunition, scrap, and upgrades; enemies are intentionally not restored mid-combat.
