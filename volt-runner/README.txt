VOLT RUNNER: Skyline Rush

Files
- index.html — complete self-contained game (HTML + CSS + JavaScript, no external assets)
- README.txt — this file

Run locally
1. Open index.html directly in Chrome/Edge/Firefox, OR
2. From this folder run: python3 -m http.server 8080
3. Open http://localhost:8080

Controls
Desktop: A/Left, D/Right, W/Up/Space jump, S/Down slide, P/Esc pause.
Mobile: Swipe left/right/up/down.

Progress is stored in localStorage in the browser.
